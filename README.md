# Quarto academic website — a first attempt!

This is my first attempt at using Quarto to design a personal academic site. I have included the following pages: About me, Publications, Grants, Teaching, CV. 
I have been inspired by a few examples, primarily information collated on Dr Gang He's website: https://drganghe.github.io/quarto-academic-site-examples.html.

## 1. Files added to folder

Relevant files (.csl referencing template, favicon.png and CV.pdf) are included in the main folder for now.
Some of the linked files (e.g. `CV.pdf`) are currently placeholders until I update their contents. Some of the content in other files, displayed as text on the relevant pages, is also to be updated.
